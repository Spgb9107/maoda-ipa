## 项目简介

茂达智联官方网站改版V1.0版本，基于2026年知识产权行业最佳实践构建。

### 技术栈
- **HTML5** — 语义化标签结构
- **CSS3** — CSS Grid + Flexbox + Custom Properties
- **Vanilla JavaScript** — 零依赖交互逻辑
- **Google Fonts** — Noto Serif SC + Noto Sans SC

### 品牌设计
- **主色调**：深邃蓝 `#1A3A5C` + 雅致金 `#C9A84C`
- **字体**：思源宋体（标题）+ 思源黑体（正文）
- **支持**：明暗主题切换、响应式设计、60fps动画

### 网站板块
1. **首页 Hero** — 企业定位 + 核心数据展示
2. **关于茂达** — 企业介绍 + 企业文化
3. **服务领域** — 专利/商标/版权/诉讼四大板块
4. **服务流程** — 六步标准化流程
5. **典型案例** — 专利/复审/商标/涉外案例
6. **合作伙伴** — 3000+客户展示
7. **联系我们** — 联系信息 + 在线咨询表单

## 本地预览

```bash
# 直接用浏览器打开
open index.html

# 或启动本地服务器
python3 -m http.server 3000
```
